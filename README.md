# Glamour Studio — Premium Unisex Salon & Spa Website
### Standard City's #1 Luxury Salon | Since 2016

---

## 🌟 About This Project

A fully responsive, high-performance website for **Glamour Studio**, a premium unisex salon & spa located in Standard City. Built with pure HTML, CSS, and JavaScript — no frameworks, no build tools, zero dependencies. 

**Deploy in 60 seconds** — just push to GitHub and connect to Vercel.

---

## ✨ Features

| Feature | Details |
|---|---|
| 🎨 **Design** | Dark luxury theme with gold accents, glassmorphism |
| 📱 **Responsive** | Mobile-first, works on all screen sizes |
| ⚡ **Performance** | Lazy-loaded images, no external JS libraries |
| 🎬 **Animations** | 3D tilt cards, parallax hero, typed text, particle effects |
| 🔍 **SEO** | Meta tags, semantic HTML, structured content |
| 📞 **Contact** | WhatsApp float button, booking form, click-to-call |
| 🗺️ **Map** | Embedded Google Maps |

## 📋 Pages / Sections

- **Hero** — Full-screen with parallax, animated stats counter, particle effects
- **Ticker** — Scrolling services marquee
- **About** — Story, features, layered image composition
- **Services** — Filterable cards for Men / Women
- **Why Us** — Dark section with hover-animated feature cards
- **Gallery** — Masonry grid with lightbox zoom
- **Team** — 4 stylists with social hover reveal
- **Testimonials** — Auto-playing slider with dots
- **Booking** — Integrated form with success state
- **Contact** — Cards + embedded Google Map
- **Footer** — Full multi-column footer
